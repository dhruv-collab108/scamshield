🛡️ ScamShield AI
Detect. Prevent. Stay Safe.
ScamShield AI is an AI-powered digital protection platform designed to help users identify potential online scams, fraudulent job opportunities, suspicious links, and misleading messages. It aims to make online activities safer by analyzing suspicious content and providing security insights.
Live Demo:https://scamshield-ai-2004.ai.studio/ 

🚀 About the Project
Online scams are increasing rapidly, especially fake job offers, phishing links, fraudulent emails, and misleading recruitment messages. ScamShield AI aims to help users identify potential threats before they become victims.

The platform combines AI-powered analysis, security checks, and a user-friendly interface to provide a smarter digital safety experience.

✨ Key Features
🔍 Scam Detection – Analyze suspicious messages, links, and job offers.
💼 Fake Job Detection – Identify potentially fraudulent recruitment opportunities.
📧 Message Analysis – Examine suspicious messages and emails for scam indicators.
📄 Resume Analyzer – Upload a resume and receive AI-based feedback.
🔗 Suspicious Link Analysis – Evaluate potentially unsafe URLs.
🤖 AI-Powered Insights – Receive explanations and recommendations.
🔐 Secure Authentication – Login system with JWT-based authentication.
📊 Modern Dashboard – Simple and interactive user interface.

⚙️ Installation & Setup
1. Clone the Repository
2. Navigate to the Project
cd project
3. Frontend Setup
cd frontend
npm install
npm run dev
Frontend will run locally at:

http://localhost:5173

4. Backend Setup
Open the backend folder in your IDE and configure the required environment variables.

Configure:

MongoDB connection
JWT secret
Gemini API key
Frontend origin
Run the Spring Boot application.

🔐 Environment Configuration
Never commit API keys, passwords, JWT secrets, or private credentials to GitHub.

Use environment variables for sensitive configurations.

Example:

MONGODB_URI=your_mongodb_connection
JWT_SECRET_BASE64=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
FRONTEND_ORIGIN=http://localhost:5173
